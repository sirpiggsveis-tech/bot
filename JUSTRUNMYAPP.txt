JustRunMy.App — deploy with ZIP (easiest)
==========================================

Use the zip. You do NOT need GitHub for this.

FILES ON YOUR PC
  C:\Users\filip\Desktop\Project\bot-deploy.zip
  C:\Users\filip\Desktop\Project\monkey-env-paste.txt

Before starting: close start-bot.bat on your PC.

STEP 1 — Sign up
----------------
1. https://justrunmy.app/discord-bots
2. Click "Start for free" / sign up (email, no card)

STEP 2 — New app
----------------
1. Dashboard → Create app / New project (wording may vary)
2. Name it: orbat-bot
3. When asked how to deploy → choose **Zip** (not Git, not Docker)

STEP 3 — Upload zip
-------------------
1. Upload: bot-deploy.zip
2. Wait until upload finishes

STEP 4 — Runtime = Python
-------------------------
Pick **Python** (3.11 or latest they offer).

STEP 5 — Install command
------------------------
Find "Install" or "Build command" and set:

  pip install -U pip && pip install -r requirements-bot.txt

(Some panels run this once on deploy.)

STEP 6 — Start command
----------------------
Set main / start / run command to:

  python scriptt.py

STEP 7 — Environment variables
------------------------------
Add these three (copy from monkey-env-paste.txt):

  DISCORD_TOKEN = (your bot token)
  GUILD_ID = (your server id)
  DATABASE_URL = (your supabase connection string)

Do not upload .env as a public file — use their Secrets / Env UI.

STEP 8 — Deploy / Start
-----------------------
Click Deploy or Start. Open **Logs**.

Good sign:
  Logged in as YourBot#1234

Bad signs:
  "No module named ..." → run install command again
  "DISCORD_TOKEN" / login failed → fix env vars
  Out of memory → free tier is only 256MB RAM; see below

STEP 9 — Discord
----------------
Bot should show online. Test: /help

Your Cloudflare panel still works (Render API + Supabase).

────────────────────────────────────────────────────────────
If the bot crashes (out of memory)
────────────────────────────────────────────────────────────
Free plan = 0.25 GB RAM. This bot is heavy (voice/TTS libs).

Try in Logs running install with lighter path — or upgrade plan.
Most ORBAT/PD commands work without /order TTS if RAM is tight.
