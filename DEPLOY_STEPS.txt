ORBAT Bot — 24/7 deploy (only the clicks YOU must do)
=====================================================

Your PC is ready. Run setup-deploy.bat to open all websites.

STEP 1 — Push latest code (one time, in terminal)
-------------------------------------------------
If git commit failed before, run these 4 lines in PowerShell inside the Project folder:

  $env:GIT_AUTHOR_NAME="filip"
  $env:GIT_AUTHOR_EMAIL="filip@users.noreply.github.com"
  $env:GIT_COMMITTER_NAME="filip"
  $env:GIT_COMMITTER_EMAIL="filip@users.noreply.github.com"
  git commit -m "Deploy helpers and panel fixes"
  git push origin main

STEP 2 — Render (bot runs 24/7 here) ~10 min
---------------------------------------------
1. Go to https://dashboard.render.com and sign in with GitHub
2. Open service "orbat-bot" (or create from Blueprint -> sirpiggsveis-tech/bot)
3. Settings -> change Plan to Starter (~$7/mo) for true 24/7
4. Environment tab:
   - Run: python scripts/copy_render_env.py
   - Open render-env-paste.txt, copy each KEY=value into Render
   - After Cloudflare (step 3), come back and fix FRONTEND_ORIGIN + POST_LOGIN_REDIRECT
5. Manual Deploy -> Deploy latest commit
6. Wait until Live. Test: https://bot-wf8x.onrender.com/api/health  (should show ok:true)

STEP 3 — Cloudflare Pages (the nice website) ~10 min
----------------------------------------------------
1. https://dash.cloudflare.com -> Workers & Pages -> Create -> Pages -> Connect Git
2. Repo: sirpiggsveis-tech/bot
3. Build settings:
     Root directory:     web/frontend
     Build command:      npm run build
     Output directory:   dist
4. Environment variable:
     VITE_API_BASE = https://bot-wf8x.onrender.com
5. Deploy. Copy your URL (e.g. https://orbat-panel.pages.dev)
6. Add to local .env:  PAGES_URL=https://YOUR-URL.pages.dev
7. Re-run: python scripts/copy_render_env.py  and update Render env vars

STEP 4 — Discord OAuth redirect ~2 min
---------------------------------------
Discord Developer Portal -> your app -> OAuth2 -> Redirects -> Add:
  https://bot-wf8x.onrender.com/api/auth/callback

STEP 5 — Test
-------------
1. Open your Cloudflare Pages URL
2. Login with Discord
3. Dashboard should show member/unit counts

STOP running the bot on your PC once Render is live (two copies conflict).
