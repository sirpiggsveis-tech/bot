ORBAT Bot — deploy (only the clicks YOU must do)
================================================

Your PC is ready. Double-click setup-deploy.bat to open all websites.

STEP 1 — Render (panel API only) ~10 min
----------------------------------------
The Discord bot runs on YOUR PC (start.bat). Render only hosts the web panel API.

1. Go to https://dashboard.render.com and sign in with GitHub
2. Open service "orbat-bot" (or New -> Blueprint -> sirpiggsveis-tech/bot)
3. Keep Plan on FREE (sleeps when idle; wakes when an admin opens the panel)
4. Environment tab — required keys:
     DATABASE_URL, SESSION_SECRET, PANEL_ADMIN_PASSWORD, GUILD_ID, FRONTEND_ORIGIN
   Optional keep-alive: run scripts/keep_alive.py every 14 min (Task Scheduler / UptimeRobot)
5. Manual Deploy -> Deploy latest commit
6. Wait until Live. Test: https://bot-wf8x.onrender.com/ping  (should show: ok)
   First visit after idle may take 30-90 seconds.

STEP 2 — Cloudflare Pages (the nice website) ~10 min
----------------------------------------------------
1. https://dash.cloudflare.com -> Workers & Pages -> Create -> Pages -> Connect Git
2. Repo: sirpiggsveis-tech/bot
3. Build settings:
     Root directory:     web/frontend
     Build command:      npm run build
     Output directory:   dist
4. Do NOT set VITE_API_BASE (leave it empty). The site proxies /api to Render.
5. Deploy. Copy your URL (e.g. https://orbat-panel.pages.dev)
6. Add to local .env:  PAGES_URL=https://YOUR-URL.pages.dev

STEP 3 — Discord OAuth redirect ~2 min
---------------------------------------
Discord Developer Portal -> your app -> OAuth2 -> Redirects -> Add BOTH:
  https://YOUR-URL.pages.dev/api/auth/callback
  https://bot-wf8x.onrender.com/api/auth/callback

STEP 4 — Link Render to your website URL ~2 min
------------------------------------------------
Run: python scripts/copy_render_env.py  (after PAGES_URL is in .env)
Update Render Environment from render-env-paste.txt, especially:
  OAUTH_REDIRECT_URI    = https://YOUR-URL.pages.dev/api/auth/callback
  FRONTEND_ORIGIN       = https://YOUR-URL.pages.dev
  POST_LOGIN_REDIRECT   = https://YOUR-URL.pages.dev
  SESSION_COOKIE_SAMESITE = lax
Then Manual Deploy again.
Push latest code first so Cloudflare gets the /api proxy in _redirects.

STEP 5 — Test
-------------
1. Open your Cloudflare Pages URL
2. Login with Discord
3. Dashboard should show member/unit counts

KEEP the Discord bot running on your PC (start.bat). Render only serves the panel API.
Do NOT run run.py on Render — it is too heavy for the free tier.
