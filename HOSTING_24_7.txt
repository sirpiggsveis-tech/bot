24/7 SERVER — NO PC REQUIRED (recommended: Oracle Cloud FREE)
=============================================================

This runs the Discord bot + panel API together 24/7 on a cloud VM ($0/month).

WHAT YOU GET
  - Bot always online in Discord
  - Panel API for Cloudflare Pages
  - Same Supabase database as now
  - Your PC can stay off

OVERVIEW (about 30 minutes once)
  1. Create free Oracle Cloud VM (Ubuntu)
  2. Copy secrets from your PC to the server
  3. Run install script (Docker)
  4. Cloudflare Tunnel for HTTPS API URL
  5. Point Cloudflare Pages at the tunnel URL

────────────────────────────────────────────────────────────
STEP 1 — Oracle Cloud free VM (~15 min)
────────────────────────────────────────────────────────────
1. https://www.oracle.com/cloud/free/ → sign up
2. Create compute instance:
     Name: orbat-bot
     Image: Ubuntu 22.04 (aarch64 / ARM — Always Free eligible)
     Shape: Ampere A1 — 1 OCPU, 6 GB RAM (free tier)
     Networking: assign public IPv4
     SSH keys: add your public key (or generate in console)
3. Note the public IP address

────────────────────────────────────────────────────────────
STEP 2 — Secrets from your PC (~5 min)
────────────────────────────────────────────────────────────
On your Windows PC in the project folder:

  python scripts/generate_server_env.py

This creates server.env (gitignored). Upload to the VM:

  scp server.env ubuntu@YOUR_VM_IP:~/server.env

(Use your Oracle username if not ubuntu — often "ubuntu" on Ubuntu images.)

────────────────────────────────────────────────────────────
STEP 3 — Install on the server (~10 min)
────────────────────────────────────────────────────────────
SSH into the VM:

  ssh ubuntu@YOUR_VM_IP

Run:

  curl -fsSL https://raw.githubusercontent.com/sirpiggsveis-tech/bot/main/deploy/install-oracle.sh | bash

If .env is missing, the script tells you. Then:

  mkdir -p ~/bot
  mv ~/server.env ~/bot/.env
  curl -fsSL https://raw.githubusercontent.com/sirpiggsveis-tech/bot/main/deploy/install-oracle.sh | bash

Check:

  curl -s http://127.0.0.1:8000/ping
  → ok

  curl -s http://127.0.0.1:8000/api/health
  → bot_ready: true (wait ~60s after first start)

Discord: bot should show ONLINE.

Auto-restart after reboot: Docker restart policy is already "unless-stopped".

────────────────────────────────────────────────────────────
STEP 4 — HTTPS for the panel API (Cloudflare Tunnel) (~10 min)
────────────────────────────────────────────────────────────
Your Cloudflare Pages site is HTTPS. The API must be HTTPS too.

1. https://one.dash.cloudflare.com → Zero Trust → Networks → Tunnels
2. Create tunnel → Cloudflared → name: orbat-api
3. Public hostname:
     Subdomain: orbat-api (or api)
     Domain: your domain on Cloudflare
     Service: HTTP → localhost:8000  (on the VM)
4. Copy the tunnel token → add to VM ~/bot/.env:
     CLOUDFLARE_TUNNEL_TOKEN=eyJ...
5. On the VM:

  cd ~/bot
  sudo docker compose --profile tunnel up -d

6. Test: https://orbat-api.YOURDOMAIN.com/ping → ok

No domain? Use a quick tunnel for testing on the VM:
  cloudflared tunnel --url http://127.0.0.1:8000
  (gives a random *.trycloudflare.com URL — update Pages when it changes)

────────────────────────────────────────────────────────────
STEP 5 — Cloudflare Pages (~2 min)
────────────────────────────────────────────────────────────
Cloudflare Pages → your project → Settings → Environment variables:

  VITE_API_BASE = https://orbat-api.YOURDOMAIN.com

Redeploy Pages. Sign in to the panel — everything should work with PC off.

────────────────────────────────────────────────────────────
PAID ALTERNATIVE: Render Starter (~$7/mo, less setup)
────────────────────────────────────────────────────────────
If Oracle signup is painful:

1. Render → orbat-bot → Starter plan
2. Build: pip install -r requirements.txt
3. Start: python run.py
4. Set DISCORD_TOKEN + all env vars
5. Keep VITE_API_BASE = https://orbat-bot.onrender.com

See render.yaml in the repo. Panel sleeps wake on free tier only — use Starter.

────────────────────────────────────────────────────────────
STOP USING ON YOUR PC
────────────────────────────────────────────────────────────
Do NOT run start-bot.bat while the server bot is online (two bots = conflict).
Only run locally for development.
